# VGM Medical Launch

Crie uma landing page moderna e profissional para uma loja de pinças medicas chamado [VGM Medical] localizado em Goiânia, Goiás 

Serviços oferecidos: Venda de pinças medicas

Design: Limpo, moderno e confiável. Paleta Azul claro e Ciano com fundo branco.

Seções: 1) Hero com título + CTA "[AÇÃO]" 
2) Catalogo 
3) Sobre nós 
4) Contato com endereço, telefone, Google Maps
 6) Rodapé com links para redes sociais

Detalhes técnicos: Responsivo, priorizando dispositivos móveis, carregamento rápido, rolagem suave, formulário de contato para WhatsApp, meta tags SEO para "Revendedora de produtos medicos"
